# Security

Security fixes apply to the current `main` branch. Report suspected vulnerabilities
privately using [GitHub private reporting](https://github.com/ycortes94/aqcareer/security/advisories/new)
when available. Otherwise contact the repository owner privately through their
GitHub profile. Do not put personal submissions, credentials or exploit details
in a public issue. Maintainers should enable private reporting in GitHub settings.

See [the security operations guide](docs/SECURITY.md) for checks, deployment,
account configuration and recovery. Do not interpret the local regression suite
as proof of production deployment, correct account permissions or legal compliance.
